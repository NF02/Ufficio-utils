#+title: Ufficio-utils
#+author: Nicola Ferru

This repository gathers several tools I use for my daily work: a collection of Zsh scripts designed to make the Linux desktop experience extremely functional. They allow for practical and fast file management and editing, optimizing the daily workflow and "saving the ball" during busy sessions.

** Requirements and Dependencies
The correct operation of =fossil= depends on the following tools:

- *Search*: ~find~ (pre-installed on most distributions).
- *Interface*: One of ~rofi~, ~fuzzel~, ~fzf~, or ~wofi~.
  - You can specify your preferred engine using the ~-m~ parameter.
- *Office Integration*: ~pcmanfm~ (file manager) and ~foot~ (terminal emulator) for seamless contextual jumping.

#+begin_quote
The script uses ~xdg-open~ as a fallback: if your file manager is correctly configured in the user's =mimeapps.list= file, =fossil= will detect it automatically.
#+end_quote

** Installing Dependencies
Required packages vary by distribution. Simply install your preferred search engine (e.g., ~fzf~ or ~rofi~):

#+begin_src shell
  # Arch Linux and derivatives
  sudo pacman -S rofi fzf xdg-utils

  # Fedora / CentOS / RHEL
  sudo dnf install rofi fzf xdg-utils

  # Debian / Ubuntu / Mint
  sudo apt install rofi fzf xdg-utils

  # Void Linux
  sudo xbps-install -S fzf rofi xdg-utils
#+end_src

** File Manager Configuration (MIME)
To ensure =fossil= uses your preferred file manager, make sure it is set as the default handler for directories:

#+begin_src shell
  # Example for setting PCManFM
  xdg-mime default pcmanfm.desktop inode/directory
#+end_src

** Note for GNOME/KDE Environments
If you are using GNOME or KDE, the command to set the default file manager requires the full =.desktop= file name:

#+begin_src shell
  # For GNOME (Nautilus)
  xdg-mime default org.gnome.Nautilus.desktop inode/directory

  # For KDE (Dolphin)
  xdg-mime default org.kde.dolphin.desktop inode/directory
#+end_src

Should these names not match, you can verify the exact =.desktop= filename present on your system with:

#+begin_src shell
  ls /usr/share/applications | grep -E 'nautilus|dolphin|thunar|pcmanfm'
#+end_src

This instantly resolves any naming ambiguity.
